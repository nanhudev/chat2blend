## 面试可以解释的决策

- 用户的完整任务是：非技术创作者不仅需要一个可看的模型，还需要能编辑、带材质和动画、可导入后续制作工具的资产。
- 核心流程是：选择 Blender → 选择保存位置 → 设置机器人配色和尺寸 → 生成资产 → 查看质量检查 → 在 Blender 编辑 → 导出并复核 .blend / GLB。官方账户授权后可用自然语言配置配色和比例。
- 已有证据是：实际桌面按钮启动可见 Blender，产生资产；19 个独立部件、15 根骨骼、UV、贴图和挥手动作通过检查，GLB 重新导入保留部件、内嵌贴图、骨骼和驱动几何体的动作。另有真实 Blender 执行器的分块、错误与恢复检查。
- 需要清楚说明：完整资产配方目前面向机械机器人，机械部件使用刚性权重。法线贴图为平面切线法线，不包含高模细节烘焙；不承诺任意自然语言生成人物、通用自动绑定或所有引擎兼容。新桌面 AI 请求仍待本人授权验收。

真实模型成功率、用户采用率、课堂效果、节省工时与成本没有测量数据，当前不写成业绩数字。263 项测试等数量仅描述测试覆盖，不代表用户效果。
